# EVENT_SCHEMA.md — Realtime Event Schemas

This document maps the real-time JSON event payloads pushed from the server WebSocket connection.

---

## 🚀 Event Types Matrix

| Event Name | Stream Scope | Description |
| :--- | :--- | :--- |
| **`market_update`** | Public/Terminal | Live quote update (OHLCV) for an active symbol |
| **`signal_update`** | Terminal | Analytical signal changes generated by Decision engine |
| **`shadow_update`** | Terminal | Changes to virtual positions (SL/TP executions, liquidations) |
| **`sre_telemetry`** | SRE Admin | Server CPU/RAM utilization and MT5 health ticks |
| **`incident_alert`**| SRE Admin | Urgent system errors or security alerts |

---

## 📁 JSON Schema Specifications

### 1. Market Update Event (`market_update`)
Fires on every new price tick of an active symbol.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "MarketUpdateEvent",
  "type": "object",
  "properties": {
    "type": { "type": "string", "const": "market_update" },
    "symbol": { "type": "string" },
    "timeframe": { "type": "string" },
    "timestamp": { "type": "string", "format": "date-time" },
    "payload": {
      "type": "object",
      "properties": {
        "open": { "type": "number" },
        "high": { "type": "number" },
        "low": { "type": "number" },
        "close": { "type": "number" },
        "volume": { "type": "integer" }
      },
      "required": ["open", "high", "low", "close", "volume"]
    }
  },
  "required": ["type", "symbol", "timeframe", "timestamp", "payload"]
}
```

### 2. Signal Update Event (`signal_update`)
Fires when the multi-timeframe Decision engine changes analytical posture.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "SignalUpdateEvent",
  "type": "object",
  "properties": {
    "type": { "type": "string", "const": "signal_update" },
    "symbol": { "type": "string" },
    "timeframe": { "type": "string" },
    "timestamp": { "type": "string", "format": "date-time" },
    "payload": {
      "type": "object",
      "properties": {
        "trend_state": { "type": "string", "enum": ["BULLISH", "BEARISH", "NEUTRAL"] },
        "intelligence_score": { "type": "integer", "minimum": 0, "maximum": 100 },
        "risk_status": { "type": "string", "enum": ["OK", "WARNING", "VIOLATION"] },
        "decision": { "type": "string", "enum": ["BUY", "SELL", "NO_ACTION"] }
      },
      "required": ["trend_state", "intelligence_score", "risk_status", "decision"]
    }
  },
  "required": ["type", "symbol", "timeframe", "timestamp", "payload"]
}
```

### 3. SRE Telemetry Event (`sre_telemetry`)
Pushed to SRE Console for live diagnostic cards.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "SreTelemetryEvent",
  "type": "object",
  "properties": {
    "type": { "type": "string", "const": "sre_telemetry" },
    "timestamp": { "type": "string", "format": "date-time" },
    "payload": {
      "type": "object",
      "properties": {
        "api_latency_ms": { "type": "integer" },
        "mt5_connected": { "type": "boolean" },
        "active_workers_count": { "type": "integer" },
        "memory_usage_pct": { "type": "number" }
      },
      "required": ["api_latency_ms", "mt5_connected", "active_workers_count", "memory_usage_pct"]
    }
  },
  "required": ["type", "timestamp", "payload"]
}
```
