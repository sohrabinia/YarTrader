# Cognitive Learning Core - Market Discovery Brain Phase 2

## 1. Executive Summary
The **Cognitive Learning Core** is the central learning partition of TradeYar AI. Designed to behave like a newborn scientist, it discovers market behavior purely through raw observation, episodic memory, hypothesis creation, out-of-sample scientific testing, independent judgment, and continuous model updating.

---

## 2. Core Architecture Flow
The learning pipeline runs sequentially:
```text
Observation -> Memory -> Association -> Discovery -> Hypothesis -> Testing -> Simulation -> Outcome -> Judge -> Learning Update -> Concept Evolution
```

---

## 3. Strict Scientific Safeguards
- **Zero Predefined Rules**: No RSI, MACD, SMA, or indicators may guide decision-making.
- **Evidence-First Confidence**: Confidence scores are strictly tied to historical sample counts and repeatability rates.
- **Independent Judge Brain**: Every virtual trade is evaluated by a separate process to avoid self-deception and cherry-picking.
