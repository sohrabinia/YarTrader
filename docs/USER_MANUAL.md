# USER MANUAL
# TradeYar AI v3.2 — Cognitive Research Platform

Welcome to the **TradeYar AI v3.2** User Manual. TradeYar AI is an advanced, non-trading cognitive research platform designed to analyze raw market structures, discover price action sequences, and build semantic memory models without the use of subjective technical indicators.

---

## 1. Safety and Passivity Policy

TradeYar AI is built strictly as a **passive, simulation-only, and read-only market research platform**.

> **CRITICAL WARNING:**
> This software **does not** contain broker order execution capabilities, transaction engines, or live trading controls. You cannot buy, sell, or place trades on live financial markets through TradeYar AI. The system is designed strictly for academic, analytical, and learning purposes.

## 4. Understanding the Cognitive Research Dashboard

The dashboard provides real-time analytical information driven by real backend providers.

### 4.1. Cognitive Intelligence Console
Displays the real-time state of the underlying brain models:
- **Observation Status (وضعیت رصد):** Represents whether the research worker is actively reading and processing the MetaTrader5 rate stream.
- **Total Memory (حافظه کل):** Cumulative count of historical price action events persisted inside the brain database.
- **Discovered Patterns (الگوهای کشف شده):** Number of unique price sequences identified by similarity metrics.
- **Validated Concepts (مفاهیم تایید شده):** Refined, persistent pattern memories that have survived chronological testing cycles.

### 4.2. Cognitive Evidence Panel
This panel contains key criteria backing the brain's real-time evaluations:
- **Historical Similarity Matches:** Shows the number of historical patterns similar to the current live sequence.
- **Memory Evidence Cases:** The empirical sample size validating the current pattern.
- **Pattern Recognition Metrics:** Active sequence duration and confidence measurements.
- **Scenario Validation Results:** Validated and rejected hypothesis ratios.
- **Confidence Sources & Research Priorities:** Active research objectives of the brain's curiosity loop.

### 4.3. Shadow Performance Panel
Provides performance metrics for virtual, simulation-only trades executed by the Shadow Trading Engine:
- **Total Virtual Trades:** Total positions simulated.
- **Successful Trades:** Successful outcomes.
- **Failed Trades:** Unsuccessful outcomes.
- **Simulation Accuracy:** Historical win-rate percentage.

### 4.4. Conversational Explainer Interface
You can interact with the brain and ask questions regarding its latest research evaluation:
1. *Why did you open this virtual trade?* (چرا این معامله را باز کردی؟)
2. *Why did you not trade?* (چرا معامله نکردی؟)
3. *What did you learn?* (چه چیزی یاد گرفتی؟)
4. *Where did you make a mistake?* (کجا اشتباه کردی؟)
5. *What do you not know?* (چه چیزی را نمی‌دانی؟)

Clicking any button returns an instant, bilingually rendered semantic breakdown generated by the independent Judge Brain.
