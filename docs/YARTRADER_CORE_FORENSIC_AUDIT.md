2. **Definitive No-Trade Root Cause Classification**:
   - Primary Classification: **`C — Planner generates WAIT`**.
   - Technical Evidence: `ExecutionIntelligencePlanner.generate_execution_plan()` evaluates structural alignment (`alignment.get("alignment")`) and market narrative state (`narrative.get("state")`). In flat or ranging market conditions, `narrative.get("state")` resolves to `"RANGE"` or `"COMPRESSION"`, triggering Line 94:
     ```python
     if narrative.get("state") in ["COMPRESSION", "RANGE"] and action != "WAIT":
         action = "WAIT"
     ```
     This forces `action = "WAIT"`. When `action == "WAIT"`, `ResearchWorker` logs the cycle as a continuation loop without dispatching to `DemoExecutionEngine` or `ShadowTradingEngine`. Thus, `demo_trades.json` = 0 and `shadow_trades.json` = 0 because **zero actionable BUY/SELL signals were generated by the trading brain during the market observation window**.
3. **Runtime Call Verification**:
   - `ResearchRuntime.run_once()`: **EXECUTED & PROVEN** (0.06s elapsed per cycle).
   - `ExecutionIntelligenceCore.evaluate_context()`: **EXECUTED & PROVEN** (returns full narrative, liquidity, zones, alignment, and plan).
   - `ExecutionIntelligencePlanner.generate_execution_plan()`: **EXECUTED & PROVEN** (returns action `"WAIT"` with 0.0 entry/SL/TP).
   - `DemoExecutionEngine.execute_demo_decision()`: **NOT CALLED** (because action is `"WAIT"`).
4. **Canonical Architectural Engine vs. Runtime Active Engine**:
   - `DecisionEngine` (`src/Decision/Intelligence/engine.py:24`) is the canonical *architectural* decision engine registered in DI, but it evaluates portfolio allocation weights (`DecisionContext`) rather than direct trade entries (`BUY`/`SELL`).
   - `AutonomousDecisionEngine` (`src/Decision/engine.py:7`) is a legacy asset-scoring engine from earlier portfolio allocation iterations.
   - `DecisionReasoningFramework` (`src/Decision/Engine/engine.py:10`) is a wrapper providing backward compatibility.

It is instantiated in unit tests (`tests/YarTrader.Tests/Execution/test_autonomous_demo_runtime.py:29`), but zero live background workers (`ResearchWorker`, `ShadowWorker`, `YarTraderWindowsService`) call it.
