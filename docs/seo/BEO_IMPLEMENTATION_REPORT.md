# YARTRADER — BRAND & ENTITY OPTIMIZATION (BEO) REPORT

## BEO Strategy, Entity Consistency & Bing/Copilot Optimization

### 1. Unified Entity Naming
Standardized entity identity strictly as `YarTrader` across OpenGraph, Twitter Cards, HTML Title/Meta, JSON-LD schemas, and footer elements, eliminating legacy or conflicting brand variations.

### 2. Schema Entity Grounding
- `Organization` Schema: ID `https://yartrader.com/#organization`
- `WebSite` Schema: ID `https://yartrader.com/#website`
- `SoftwareApplication` Schema: `YarTrader Terminal`

### 3. Bing & Copilot Discoverability
- Clean, crawlable URL architecture with reciprocal hreflang links.
- Explicit disallow rules in `robots.txt` keeping internal SRE and private trading data isolated while surfacing public marketing, pricing, and guide content.
