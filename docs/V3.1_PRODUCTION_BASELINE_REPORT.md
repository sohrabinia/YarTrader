1. **FastAPI Web Service Host:** Serves bilingual responsive dashboard SPA. Active on port `8000`.
2. **Research Polling Worker:** Active H1 research polling loop. Supresses analysis when MT5 is disconnected.
3. **Intelligence Worker:** Evaluates price action sequence events under the four-layered cognitive memory engine.
4. **Shadow Trading Worker:** Runs virtual position lifecycle (`OPEN -> MONITORING -> CLOSED`). Monitors SL/TP exits.
5. **Independent Judge Brain:** Vets simulation outcomes, checking reasoning quality and filtering lucky wins.
6. **Server Watchdog:** Independent, zero-dependency supervisor thread executing resource guard checks.

## 5. Operating Mode & MT5 Isolation

* **Read-Only MT5 Connectivity:** Locked to read-only API data streaming (`copy_rates_range` with synthetic mock fallback). No trading functionality is present or enabled.
* **Virtual Positioning:** All execution occurs strictly in the high-fidelity shadow trading position manager using a starting virtual balance/equity of **$10,000.00**.
* **Known Operational Boundaries:** If MetaTrader 5 is disconnected, the research pipeline suppresses active output, goes into a `DEGRADED` state, and awaits reconnection. This is the expected and designed fail-safe behavior.
