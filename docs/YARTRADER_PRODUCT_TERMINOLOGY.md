1. Backtest
Canonical English: Historical Backtest
Canonical Persian: بک‌تست تاریخی (Historical Simulation)
Canonical Turkish: Geçmiş Backtest
Canonical Arabic: الاختبار الخلفي التاريخي
Definition: Algorithmic trade simulation executed on historical price feeds without broker order routing. Point-in-time protected.
Avoid: معاملات واقعی, Live Trading, Real Broker Order

2. Demo
Canonical English: Demo Trading
Canonical Persian: معاملات دمو (Real Market + Demo Account)
Canonical Turkish: Demo İşlem
Canonical Arabic: التداول التجريبي
Definition: Real-time market feed connected to an official MT5/MT4 demo broker account (e.g. Alpari Demo 52961173).
Avoid: معاملات واقعی, Real Money Trading

3. Shadow
Canonical English: Shadow / Paper Trading
Canonical Persian: معاملات سایه (Real Market + Paper Execution)
Canonical Turkish: Gölge / Sanal İşlem
Canonical Arabic: التداول الوهمي (Paper)
Definition: Real-time market data evaluation and virtual position tracking ($1,000 USD paper account YARTRADER-PAPER-001) without broker order submission.
Avoid: معاملات فرضی, Hypothetical Trade, Mock Trade

4. Live
Canonical English: Live Trading (Blocked)
Canonical Persian: معاملات واقعی (Hard Blocked)
Canonical Turkish: Canlı İşlem (Engellendi)
Canonical Arabic: التداول الحقيقي (محظور)
Definition: Real-money live trade execution. Permanently fail-closed by SRE MetaTraderSafetyGate.
Avoid: Live Active, Production Active, Trading Enabled

5. Signal
Canonical English: Signal
Canonical Persian: سیگنال
Canonical Turkish: Sinyal
Canonical Arabic: إشارة
Definition: Qualified market opportunity output generated by cognitive intelligence analysis before decision/order stages.
Avoid: معامله, Trade, Position

6. Decision
Canonical English: Decision
Canonical Persian: تصمیم استراتژیک
Canonical Turkish: Karar
Canonical Arabic: قرار
Definition: Multi-agent synthesis evaluation (Research + Strategy + Risk) determining posture (BULLISH/BEARISH/WAIT).
Avoid: سفارش, Trade, Order

7. Order
Canonical English: Order
Canonical Persian: سفارش
Canonical Turkish: Emir
Canonical Arabic: أمر
Definition: Formal request sent to virtual account manager or MT5 terminal (BUY/SELL at price with SL/TP).
Avoid: معامله انجام‌شده, Execution

8. Execution
Canonical English: Execution
Canonical Persian: اجرای معامله
Canonical Turkish: İnfaz / Uygulama
Canonical Arabic: تنفيذ
Definition: The physical or simulated filling of an order (creating a open position with ticket or VPOS ID).
Avoid: سیگنال, Signal

9. Trade
Canonical English: Trade
Canonical Persian: معامله
Canonical Turkish: İşlem
Canonical Arabic: صفقة
Definition: An active or closed position from entry to exit with calculated realized/unrealized PnL.
Avoid: سیگنال, Signal

10. Research
Canonical English: Market Research
Canonical Persian: پژوهش بازار
Canonical Turkish: Piyasa Araştırması
Canonical Arabic: أبحاث السوق
Definition: Technical and structural feature extraction without immediate execution commitment.

11. Learning
Canonical English: Cognitive Learning
Canonical Persian: یادگیری شناختی
Canonical Turkish: Bilişsel Öğrenme
Canonical Arabic: التعلم المعرفي
Definition: Four-layered memory system updating pattern confidence weights based on post-trade evaluation.

12. Pattern
Canonical English: Structural Pattern
Canonical Persian: الگوی ساختاری
Canonical Turkish: Yapısal Desen
Canonical Arabic: نمط هيكلي
Definition: Recognized sequence of swing highs/lows, Order Blocks, or FVGs across canonical timeframes.

13. Risk
Canonical English: Risk Management
Canonical Persian: مدیریت ریسک
Canonical Turkish: Risk Yönetimi
Canonical Arabic: إدارة المخاطر
Definition: SRE portfolio heat controls, drawdown limits, and position sizing rules.

Canonical English: Cognitive Confidence
Canonical Persian: ضریب اطمینان شناختی
Canonical Turkish: Güven Oranı
Canonical Arabic: درجة الثقة

15. Evidence
Canonical English: Statistical Evidence
Canonical Persian: شواهد آماری
Canonical Turkish: İstatistiksel Kanıt
Canonical Arabic: أدلة إحصائية

Canonical Arabic: مجموعة البيانات
