# 12. Admin Dashboard

## 1. Overview & Modules

The administration dashboard provides complete operational visibility and telemetry diagnostics for platform monitors, without displaying any trading or transaction triggers.

---

## 2. Dashboard Sub-screens

### System Overview Dashboard
Aggregates health diagnostics, service statuses, pipeline states, and audit checks.

### Agent Management Dashboard
Tracks active agent lifecycles, capability tags, reliability scores, and performance histories.

### Decision Intelligence Dashboard
Provides decision tracing, evidence sources, quality scores, and resolved conflict histories.

### Data Provider Dashboard
Tracks data source availability, latencies, failure rates, quality reports, and health states.

### Knowledge Intelligence Dashboard
Displays knowledge graph node/edge growths, evidence links, and query counts.

### Audit & Security Dashboard
Tracks APES-FIN compliance, execution leakage status, layer isolation checks, and test statuses.
