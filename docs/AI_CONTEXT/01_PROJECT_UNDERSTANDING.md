# 01. Project Understanding

## 1. Project Vision & Mission
The **RG_V3 Autonomous Financial Intelligence Platform** (RG_V3_AI) is designed as a passive, non-trading system to orchestrate and model high-fidelity financial intelligence, macroeconomic research, and risk bounds analysis.

Its mission is to provide an off-grid, sandboxed environment for testing multi-agent collaborative reasoning, semantic knowledge relations indexing, and parameter optimizations.

## 2. Core Philosophy
Decouple financial analysis and portfolio modeling from the mechanics of trading execution. In doing so, the platform remains free from execution bottlenecks, slippage constraints, or broker-integration vulnerabilities.

---

## 3. Goals & Non-Goals

### Goals
*   **Decoupled Intelligence**: Construct a unidirectional pipeline from raw data to structured decision context.
*   **Dynamic Agent Collaboration**: Support priority-confidence compromise resolution across agents.
*   **Provider Independence**: Query financial and macroeconomic data feeds through unified gateways without platform-specific lock-ins.
*   **Absolute Compliance**: Guarantee 100% adherence to APES-FIN passive guidelines.

### Non-Goals
*   No automated trading logic.
*   No order dispatch, entry, or position size modifications.
*   No execution connections to active financial brokers.
*   No machine learning training loops or prediction forecasting models.

---

## 4. What the System IS vs. What It IS NOT

| The System IS | The System IS NOT |
| :--- | :--- |
| Passive research reasoning framework | Trading Bot / Automated Execution |
| Collaborative multi-agent network | Signal Generator / Trade Trigger |
| Provider-independent data gateway | Broker Terminal / Portfolio Executor |
| Multi-factor risk limit auditor | Money Management / Active Size Modifier |
