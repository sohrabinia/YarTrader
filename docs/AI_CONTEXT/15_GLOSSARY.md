# 15. Glossary

## 1. Technical Terms

### APES-FIN Compliance
Clean design standard mandating that financial software remains purely analytical, passive, and strictly decoupled from trade execution or active broker terminals.

### Dynamic Agent Selection
The process of dynamically matching and choosing the best subset of active agents to perform a task based on focus area alignment and dynamic priority scores.

### Execution Leakage
Any potential occurrence of order, trade, or transaction-related code/imports entering secure analytical scopes.

### Knowledge Graph
A semantic relationship network connecting assets, agents, metrics, and regimes.

---

## 2. Financial & Ingestion Terms

### CandleRecord
Value object standardizing market snapshot bars (timestamp, open, high, low, close, volume).

### Economic Calendar Event
Macroeconomic indicators (CPI, Non-Farm Payrolls, GDP) used as inputs to passive research.

### Exposure Analysis
Quantitative measurements evaluating concentration metrics and boundary exposures.

### PortfolioRisk
Value object containing expected annualized volatility and historical drawdowns.
