# Live Cognitive Analysis Engine

## 1. Overview
The **Live Market Observer** and **Real-Time Context Builder** stream ticks, bids, asks, and spreads dynamically from the read-only MetaTrader 5 terminal, mapping these observations into the standard `AnalysisBrain` and `DecisionEngine`.

---

## 2. Dynamic Real-Time Context
The system structures current price movement, similar historical patterns, active hypotheses, and current uncertainty into a unified market understanding context. Predefined technical indicators and human trading rules are strictly prohibited from guiding live reasoning.
