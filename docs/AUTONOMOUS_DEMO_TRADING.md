# YarTrader Autonomous Demo Trading Architecture & Operations Manual

**Version:** 1.2.0
**Status:** Certified & Operational
**Target Platform:** MetaTrader 5 DEMO (`52961173` @ `Alpari-MT5-Demo`)
**Live Execution Boundary:** Hard-Blocked (`LIVE_TRADING_ENABLED=False`, Fail-Closed)

## 1. Unified Single Source of Truth Pipeline

YarTrader operates a single, unified decision pathway:

```text
REAL MARKET DATA
       ↓
ResearchRuntime
       ↓
Feature Extraction
       ↓
ExecutionIntelligenceCore (Narrative, Liquidity, Zones, Alignment, Similarity)
       ↓
ExecutionIntelligencePlanner
       ↓
AutonomousTradingDecision (Immutable Contract)
       ↓
Decision Gate & Risk Gate (RR >= 1.5, Conf >= 50.0, Portfolio Risk, Cooldown, Kill Switch)
       ↓
DemoExecutionGate & MetaTraderSafetyGate
       ↓
RealMT5BrokerAdapter (order_check → order_send)
       ↓
MT5 DEMO Terminal Execution
       ↓
Position Monitoring
       ↓
Trade Outcome & Journal
       ↓
Outcome Analyzer & Pattern Memory
       ↓
Evidence-Based Learning
       ↺
```

## 3. Risk, Safety & Kill Switch Controls

1. **Kill Switch:** Controlled via `AUTONOMOUS_DEMO_TRADING_ENABLED` environment variable. When set to `False`, autonomous order dispatching is halted immediately while research polling continues.
2. **Risk & Confidence Gates:**
   - Minimum Risk-Reward: `MINIMUM_RR` (default `1.5`).
   - Minimum Confidence: `MINIMUM_CONFIDENCE` (default `50.0`).
3. **Duplicate & Cooldown Protection:**
   - Active per-symbol cooldown tracking prevents duplicate order submission.
4. **Safety Gates:**
   - `DemoExecutionGate` verifies connected account (`52961173`), server (`Alpari-MT5-Demo`), `trade_mode == 0` (DEMO), and terminal trading permissions.
   - `MetaTraderSafetyGate` hard-blocks any attempt to execute on MT5 Live or MT4 Demo accounts.

---

## 4. Retcode Handling & Market Closed Recovery

All order submissions perform `order_check` prior to `order_send`.
When retcode `10018 MARKET_CLOSED` is returned by MT5, `DemoExecutionEngine` classifies it as a safe market availability rejection (`MARKET_CLOSED`). The system records the attempt and returns safely to the polling loop without marking the decision logic as failed.
