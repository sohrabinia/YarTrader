# TradeYar AI Growth Model and Conversion Funnel

Describes acquisition, retention rates, conversion ratios, and peer referral loops.

## Conversion Funnel Stages
1. **Visitor**: Anonymous landing traffic.
2. **Content Reader**: Explores pricing, public website guides, or blog articles.
3. **Registered User**: Signs up for an account via social authentication or credentials.
4. **Active User**: Regularly monitors terminal signal feeds.
5. **Premium Candidate**: Engages with subscription plan panels.

## Referral tracking
Peer invites are tracked through deterministic tokens containing target reward structures, helping SREs safely track affiliate conversions.
