# TradeYar AI Search Engine Optimization (SEO) Strategy

This outlines search engine indexing guidelines, semantic keyword densities, and metadata optimization checklists to build search engine authority.

## Optimization Checklist
- **Length Boundaries**: Document metadata titles must match between 30 and 60 characters; description snippets must match between 120 and 160 characters.
- **Focus Keyword Density**: Target key terms should have a density of 1.5% to 2.5% per page (such as "multi-timeframe decision fusion", "apes-fin compliance", and "subjective indicators decoupling").
- **Competitor Gaps**: Maintain weekly automated competitive audits to capture new keyword trends and suggestions.
