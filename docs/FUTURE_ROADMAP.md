# TradeYar AI — Future Intelligence Roadmap

This roadmap defines the sequential expansion of the Market Discovery Brain's intelligence following the stabilization of the current architecture.

## Phase 1: Architecture Stabilization (Current)
- Establish strict module contracts, immutable decisions, isolated Judge Brain, and intelligence integrity checks.
- Build robust unit and integration testing gates protecting boundary rules.

## Phase 2: Fractal Multi-Scale Recurrence Intelligence
- Move beyond static multi-timeframe mapping to discover scale recurrence patterns.
- **Objective:** Answer whether sequence structures observed on M1 and M5 exhibit mathematical similarity to structures observed on H4 and Daily (Fractal recurrence).
- **Hypothesis Testing:** Test parent-child relationship propagation and scale-invariant similarity matches.

## Phase 3: Read-Only Conversation Interface
- Introduce the natural language interaction layer.
- **Strict Boundary constraint:** The Conversation Layer has zero direct writing capabilities to Memory, and zero execution endpoints.
- **Query Architecture:**
  ```
  Conversation UI --> KnowledgeQueryInterface (Read-Only) --> Memory System
  ```
- Use LLMs/parsers strictly as a natural translation interface to retrieve read-only brain status, current hypotheses, and learning scorecards for human review.
