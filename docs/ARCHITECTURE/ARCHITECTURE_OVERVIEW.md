# Architecture Overview

The system architecture focuses heavily on decoupling business rules from external network adapters. It consists of the following master components:
- **Passive Multi-Agent Supervisor Loop**: Research Agent, Strategy Analyst, Risk Agent, Validation Agent, and Learning Agent.
- **Advanced Decision Intelligence Core**: Processes multi-dimensional context validations, logical evaluations, logical conflict resolution, and evidence trails.
- **Simulation-Only Ingest Adapters**: Standard MT5, Calendar, and News read-only providers.
