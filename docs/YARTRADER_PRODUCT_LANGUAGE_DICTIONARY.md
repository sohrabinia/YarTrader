## Core Product Terminology Dictionary

```
1.
English Term: Autonomous Command Center
Persian Term: خانه هوشمند
Usage Rule: Used strictly for the main dashboard hero and header (/dashboard).
Forbidden Alternative: صفحه اصلی, داشبورد ساده, ربات معامله‌گر
Example: "به خانه هوشمند YarTrader خوش آمدید."

2.
English Term: Market Insights
Persian Term: بینش‌های بازار
Usage Rule: Used for quantitative signal feeds and market intelligence cards.
Forbidden Alternative: سیگنال‌های فروشی, پیش‌بینی قیمت, کانال سیگنال
Example: "بینش‌های فعال بازار در تایم‌فریم H1"

3.
English Term: Decision Intelligence
Persian Term: هوشمندی تصمیم‌گیری
Usage Rule: Used for XAI rationale, 5-stage cascade, and advisory trade plans.
Forbidden Alternative: پیش‌بینی مصنوعی, دستور ربات, تصمیم اتوماتیک
Example: "شواهد هوشمندی تصمیم‌گیری برای نماد XAUUSD"

4.
English Term: Risk Intelligence & Control
Persian Term: مدیریت و کنترل ریسک
Usage Rule: Used for portfolio heat, drawdown limits, exposure, and emergency stop.
Forbidden Alternative: حد ضرر ساده, ریسک ربات, کنترل خطر
Example: "سطح بودجه ریسک و حرارت سبد سرمایه‌گذاری"

5.

Persian Term: هوش فراکتالی بازار

Forbidden Alternative: الگوی هندسی, هندسه بازار, فراکتال ساده

7.
English Term: Paper Execution / Shadow Trading

Usage Rule: Used for virtual capital ($1,000) paper trading simulations.
Forbidden Alternative: معاملات فرضی, معامله خیالی, تست معامله
Example: "موقعیت باز در حساب معاملات سایه"

9.
English Term: Position Lifecycle
Persian Term: چرخه حیات موقعیت معامله
Usage Rule: Used for the 5-stage position timeline stepper.
Forbidden Alternative: مراحل پوزیشن, وضعیت سفارش, لایف‌سایکل
Example: "چرخه حیات: ایجاد شده ← ارزیابی‌شده ← بازشده ← مدیریت‌شده ← بسته‌شده"

10.
English Term: Continuous Learning Loop
Persian Term: یادگیری مستمر سیستم
Usage Rule: Used for pattern performance matrix and model adaptation feedback.
Forbidden Alternative: هوش خودکار, آموزش ربات, یادگیری ماشین

Example: "سطح هدف معامله: 2,685.00 $"

English Term: SRE Control Plane
Persian Term: مرکز عملیات و پایش سیستم (SRE)

Forbidden Alternative: پنل مدیریت, بخش ادمین, کنترل ربات

English Term: Wallet & Ledger Balance

Forbidden Alternative: حساب پول, شارژ حساب, موجودی
Example: "موجودی اعتبار و صورت‌حساب تراکنش‌ها"
```
